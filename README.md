프로젝트 개요
Unity 기반 3D 방탈출 게임으로, 퍼즐 상호작용, 아이템 수집 상태가 변경되는 구조를 구현했습니다. 사용자 입력과 게임 상태 변화가 직접적으로 연결되는 상호작용 중심의 게임 시스템을 설계했습니다.

주요 기능

마우스 입력 기반 퍼즐 오브젝트 상호작용
Key 아이템 수집 및 상태 기반 퍼즐 진행
RenderTexture 기반 미니맵 UI 출력
Coroutine 기반 이벤트 연출 및 상태 변화 처리
3인칭 및 1인칭 카메라 전환 기능

담당 역할

Unity 기반 3D 게임 시스템 전체 설계 및 1인 개발
카메라 전환 로직 및 입력 처리 구조 구현
퍼즐 오브젝트 상호작용 로직 설계
아이템 수집 및 상태 관리 로직 구현
미니맵 UI 및 이벤트 연출 기능 구현

기술 스택
Unity / C#

개발 목적 및 배운 점
게임 기능을 개별적으로 구현하는 것이 아닌, 카메라 전환·퍼즐 상호작용·아이템 수집을 상태 값으로 관리하며 전체 흐름을 설계하는 경험을 쌓았습니다. 입력 이벤트 처리와 상태 변화 타이밍 제어를 통해, 이벤트 기반 시스템에서 상태 관리와 구조 설계의 중요성을 이해하게 되었습니다.
