# Escape Tower - 3D 방탈출 게임

Unity 기반 3D 방탈출 게임입니다. 마우스 입력으로 퍼즐 오브젝트와 상호작용하고, 아이템 획득 여부에 따라 퍼즐이 진행되는 구조로 만들었습니다.

- YouTube: https://www.youtube.com/watch?v=HS-QF0Z39VY
- 포트폴리오: https://github.com/kimseoyeon6465/Portfolio

## 주요 기능

- 마우스 입력 기반 퍼즐 오브젝트 상호작용 (드래그, 충돌, 회전)
- Key 아이템 획득과 상태 기반 퍼즐 진행
- 3인칭, 1인칭 카메라 전환
- RenderTexture 기반 미니맵 UI
- Coroutine 기반 이벤트 연출과 상태 변화 처리
- 시간 제한과 환경 요소를 결합한 퍼즐 구성

## 핵심 구현

- **상태 관리:** 퍼즐 진행, 아이템 획득, 상호작용 결과를 `GameController` 중심으로 관리하고, 퍼즐 오브젝트는 트리거 역할만 수행합니다.
- **상호작용 분리:** 드래그, 충돌, 회전 기반 상호작용을 오브젝트 단위로 분리했습니다.
- **아이템 처리:** 아이템 획득과 사용을 분리하고, 획득 여부만 상태로 저장합니다.
- **이동과 카메라:** 플레이어 이동과 카메라 제어를 분리했습니다.
